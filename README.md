# Wondoo — 2D 파밍 RPG 프로토타입

Windows 11에서도 가볍게 실행할 수 있는 블레오 스타일 2D 파밍 게임을 개발하는 저장소입니다.

> 현재 단계: Godot 4 기반 **로컬 프로토타입**. 서버, 멀티플레이, 원본 이미지 리소스는 아직 포함되지 않았습니다.

## 실행 방법

1. [Godot Engine](https://godotengine.org/download/) 4.x를 설치합니다.
2. 이 저장소를 내려받습니다(초록색 **Code → Download ZIP**).
3. Godot 프로젝트 관리자에서 **Import**를 누르고 저장소의 `project.godot` 파일을 선택합니다.
4. 프로젝트를 연 뒤 **F6이 아닌 F5**로 메인 장면을 실행합니다.

## 기본 조작

- **마우스 왼쪽 클릭**: 클릭한 위치까지 자동 이동(클릭 투 무브)
- **W**: 걷기/달리기 전환
- **달리면서 이동**: 스테미나(ST) 소모. ST가 0이 되면 자동 걷기 전환
- **I**: 인벤토리 열기/닫기
- **ESC**: 인벤토리 닫기

## 현재 구현 범위

- 이미지 파일 없이 도형으로 표시되는 임시 캐릭터와 고정 몬스터
- 클릭 이동, 걷기/달리기, 스테미나 소모와 회복
- 임시 인벤토리 UI
- 외부 에셋이 필요 없는 저사양 지향 화면

## 폴더 구조

```text

scripts/main.gd       초기 이동·ST·UI 프로토타입
```
