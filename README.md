# WONDOO — 포켓 파밍 RPG

블레오 스타일로 만드는 가벼운 2D 파밍 게임 프로젝트입니다.

## 📱 휴대폰에서 바로 실행하기 (가장 쉬운 방법)

**HTML5 모바일 프로토타입**은 `index.html` 하나로 완성된 오프라인 게임입니다.

1. 이 저장소에서 **Code → Download ZIP**을 누릅니다.
2. 휴대폰의 파일 앱에서 ZIP 압축을 풉니다.
3. 풀린 폴더 안의 **index.html**을 웹 브라우저로 엽니다.
4. 땅을 터치하여 이동하고, 몬스터를 터치해 자동 공격해 보세요!

> Android: 파일 앱에서 HTML을 브라우저로 열 수 있는 환경에서 실행됩니다. 기종에 따라 직접 열기가 제한될 수 있습니다.
>
> iPhone/iPad: 파일 앱의 HTML 미리보기에서는 JavaScript 실행이 제한될 수 있습니다. 이 경우 GitHub Pages 같은 HTTPS 웹 주소로 배포해야 Safari에서 더 안정적으로 플레이할 수 있습니다.

### 터치 조작

- **필드 터치:** 캐릭터가 해당 위치로 자동 이동
- **몬스터 터치:** 대상에게 접근하고 자동 공격
- **⚔️ 공격:** 가까운 몬스터를 선택하여 공격
- **🏃 달리기:** 걷기/달리기 전환 (ST가 0이면 자동 걷기)
- **🎒 가방:** 획득한 아이템 확인 및 터치해서 장비 착용
- **🧪 회복:** 체력 회복 물약 사용
- **🗺️ 사냥터:** 초록 숲 / 잊힌 유적 전환

몬스터는 움직이지 않고 지정된 위치에서 등장합니다. 적 처치 시 골드·경험치·장비를 획득할 수 있습니다. 장비의 추가 옵션은 노멀 0개, 레어 1개, 희귀 2개, 에픽 3개입니다.

**현재 한계:** 임시 그래픽과 테스트용 전투입니다. 실제 블레오 리소스, 정식 강화 시스템, 서버 멀티플레이는 아직 구현되지 않았습니다.

## 💻 기존 Godot 프로젝트

`project.godot`, `scenes/main.tscn`, `scripts/main.gd` 파일은 별도 데스크톱 프로토타입입니다. Godot 4.x로 가져와 F5 키를 눌러 실행할 수 있습니다. **휴대폰에서는 Godot 프로젝트가 아닌 `index.html`을 사용하세요.**

## 주의

권리 확인이 끝나지 않은 게임 원본 이미지나 비밀번호, 서버 키는 공개 저장소에 업로드하지 마세요. 장기적으로 계정 및 캐릭터 데이터 보안이 필요한 온라인 게임은 별도의 서버 개발이 필요합니다.
